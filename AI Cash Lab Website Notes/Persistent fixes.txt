SEO/content card layout persistence

- Repeated issue: SEO intro/content sections can become extremely narrow when inserted inside tool pages that use CSS grid layouts.
- Symptoms:
  - SEO paragraph block appears as a skinny vertical column.
  - Text wraps one or two words per line.
  - Card background may appear correct, but the section is trapped inside one grid column.
- Required fix for shared SEO/content blocks:
  - Apply to both `.acl-seo-intro` and `.seo-content`.
  - Include `grid-column: 1 / -1 !important`.
  - Include `justify-self: stretch !important`.
  - Include `align-self: stretch !important`.
  - Include `min-width: 0 !important`.
  - Include centered card width such as `width: min(calc(100% - 32px), 1120px) !important`.
- Before committing SEO/layout fixes:
  - Preview at least the originally reported page.
  - Check 2-3 neighboring tools in the same cluster.
  - Confirm computed layout is full-width, not trapped in a grid column.
  - Commit and push only after the visual/layout issue is confirmed fixed.
